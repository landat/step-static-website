Не получается войти?

Для входа нужен ваш личный токен GitHub и право записи в репозиторий сайта. Токен, сохранённый на landat.github.io, не переносится автоматически на meteorboxing.ru или в другой браузер.

Если токен истёк или отозван, создайте новый в своей учётной записи по инструкции первого входа. Если токена нет, первоначальную настройку нужно завершить с владельцем сайта. Пароль GitHub в поле токена не подходит. Сам токен никому не отправляйте.

Эта проверка не использует токен и не проверяет право редактирования. Если вход не работает, сообщите точный текст ошибки после попытки входа.
