Как обновить сайт МЕТЕОР

Панель работает на Sveltia CMS. Оплачивать CMS, отдельный сервер или домен не нужно.

Первый вход

Попросите разработчика помочь с первоначальной настройкой. Нужна ваша учётная запись GitHub с правом записи в репозиторий landat/step-static-website.

  1. Примите приглашение в репозиторий, если разработчик его отправил.
  2. Создайте токен доступа в своей учётной записи GitHub по инструкции ниже.
  3. Откройте панель управления и нажмите «Войти с помощью токена доступа».
  4. Вставьте токен и выполните вход. В этом браузере он сохраняется для последующих посещений.

Токен — как пароль. Не отправляйте его в переписку, не добавляйте в файлы сайта и не используйте чужой токен. Входите на своём устройстве. После окончания срока токена нужно создать новый и войти повторно.

Настройка токена — для разработчика

Владелец репозитория: создайте fine-grained token, выберите только step-static-website и разрешение Contents: Read and write. Metadata: Read добавляется автоматически. Выберите ограниченный срок, например 90 дней. Pull requests и Workflows для редактирования через эту панель не нужны.

Тренер с отдельной учётной записью: fine-grained токены GitHub пока не поддерживают запись в чужой личный репозиторий для приглашённых collaborators. Для этого публичного репозитория используйте classic token с областью public_repo в учётной записи тренера и сроком, например 90 дней. Эта область распространяется на все публичные репозитории, доступные его аккаунту, а не только на этот сайт. Области repo и workflow не требуются. Если репозиторий станет приватным, схему доступа нужно пересмотреть.

Токен не заменяет приглашение: учётная запись должна иметь право записи. Не выдавайте тренеру токен владельца. Документация GitHub о токенах и ограничениях.

Изменить текст или расписание

  1. В меню «Что изменить?» выберите нужный раздел. На телефоне меню находится над редактором и прокручивается вбок.
  2. Панель сразу перейдёт к нужным полям. Для изменения новости, фотографии или группы раскройте её карточку стрелкой.
  3. Измените поля. В списках можно добавлять, удалять и переставлять элементы; переключатель «Показывать на сайте» временно скрывает карточку.
  4. Нажмите «Сохранить». Подождите публикации GitHub Pages, обычно несколько минут, затем обновите страницу сайта.

Все разделы сохраняются вместе. Не редактируйте сайт одновременно в двух вкладках или в старой CMS. Если панель сообщает о конфликте, обновите данные и повторите изменения.

Все тексты страниц

В разделе «Тексты страниц» раскройте нужную страницу: здесь меняются заголовки, абзацы, списки, подписи кнопок, меню, подвал и описания для поиска. Название поля содержит исходный текст, а поля идут по порядку страницы. Новости, расписание, цены, контакты и основной текст «О нас» редактируются в своих разделах. Надписи внутри фотографий и внешней карты не являются текстом сайта.

Если появилась ошибка NetworkError

Не обновляйте вкладку с несохранёнными изменениями: сначала скопируйте тексты в заметки. В левой панели откройте «Если не сохраняется» и проверьте соединение с GitHub. Если ответа нет, попробуйте другую сеть. После восстановления связи проверьте опубликованный результат в другой вкладке и при необходимости повторите сохранение. Проверка читает публичный репозиторий; она не проверяет токен и права записи. Если ошибка повторяется, сообщите время, браузер, что сохраняли и результат проверки. Не отправляйте токен.

О нас, фон главной и стоимость занятий

В разделе «О нас» меняются заголовок, основной текст и фотография отдельной страницы. Фото можно загрузить или выбрать в медиатеке; оно показывается целиком. В разделе «Главная» выберите фото или видео первого экрана. Для фона лучше подходит горизонтальный снимок; пустое поле возвращает исходное фото.

Фото рядом с карточками «Основные направления» меняется отдельно: «Главная» → «Фото или видео блока «Основные направления»». Выберите снимок и нажмите «Сохранить». Раздел «Фото и видео» и его галочка «Показывать на сайте» управляют только галереей.

В «Цены» меняются варианты занятий, стоимость, пояснение и текст кнопки блока на главной. Возраст приёма — с 11 лет.

Фото или видео в любом блоке

В новостях, галерее, «О нас», первом экране и «Основных направлениях» можно выбрать JPG, PNG, WebP или видео MP4/WebM до 50 МиБ. Тип определяется автоматически. После выбора нажмите «Сохранить». Для телефонов лучше MP4 с H.264/AAC. Видео запускается по нажатию; фоновое видео — без звука, с кнопкой паузы. Видео не сжимается автоматически. Ссылки Rutube доступны в разделе «Видеоуроки».

Загрузка файлов

В поле файла нажмите кнопку выбора, затем загрузите файл или выберите существующий. Фотографии: JPG, PNG, WebP; видео: MP4, WebM; документы: PDF, DOC, DOCX. Лимит загрузки в этой панели — 50 МиБ на файл. Для больших видео используйте Rutube.

В галерее добавьте подпись к фото или видео. В разделе «Видеоуроки» выберите тип «Загруженный MP4/WebM» или «Rutube» и заполните соответствующее поле. В остальных блоках достаточно выбрать файл. Для документа добавьте название, текст и при необходимости файл.

Новые фотографии автоматически обрабатываются существующей задачей после загрузки в GitHub. Для ручного сжатия используйте «Уменьшить большие фото», затем на GitHub выберите Run workflow → main → Run workflow. Дождитесь зелёной отметки выполнения.

Если что-то не работает

  • Ошибка входа: проверьте срок токена, область доступа и принятие приглашения.
  • Панель открылась, но данные не загрузились: проверьте доступность api.github.com и сообщите разработчику текст ошибки.
  • Сайт не изменился: подождите 5 минут, обновите его через Ctrl+F5 и проверьте публикацию GitHub Pages.
