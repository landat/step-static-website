# Школа бокса МЕТЕОР

Статический сайт школы бокса МЕТЕОР для публикации на GitHub Pages.

## Основные страницы

- `index.html` - главная, включая блок «Стоимость и запись» и редактируемый фон первого экрана
- `about.html` - о нас, с редактируемыми основным текстом и фотографией
- `prices.html` - переход к блоку «Стоимость и запись» на главной
- `photos.html` - фото
- `training.html` - тренировки
- `schedule.html` - расписание
- `beginners.html` - уроки начинающим и видео
- `reviews.html` - перенаправление со старого раздела отзывов на фото
- `contacts.html` - контакты

## Видео и материалы для новичков

Превью обзорного ролика — его первый кадр, сохранённый в `assets/videos/meteor-overview-first-frame.png`. `npm run build:home-images` сжимает этот кадр в `assets/optimized/video-poster.webp`. Видео на главной сохраняет `preload="none"`: для превью загружается только картинка. При замене ролика исходный кадр можно получить командой `ffmpeg -i assets/videos/meteor-overview.mp4 -frames:v 1 -update 1 assets/videos/meteor-overview-first-frame.png`.

Видео, ссылки Rutube и карточки материалов редактируются через Sveltia CMS. Загруженные видео хранятся в `assets/videos`, документы — в `assets/materials`.

Подробная инструкция:

- в репозитории: `ADMIN_GUIDE.md`

## Карта и аналитика

- Карта на странице `contacts.html` вставлена через iframe-виджет Яндекс.Карт без API key.
- Аналитика подключается в `assets/site.js` через GoatCounter: `https://step-static-website.goatcounter.com/count`.
- Скрипт аналитики не использует cookies и не загружается на `localhost` или при открытии файлов через `file:`.
- Яндекс Метрика загружается только после согласия посетителя. Для включения укажите выданный Яндексом номер в `METEOR_YANDEX_METRIKA_ID` в `assets/site.js`.

## Управление содержимым

Файл `content/site.json` — единый источник для объявления, расписания, контактов, цен, новостей, фотографий, видео, материалов и рассказа о школе. Бесплатная Sveltia CMS расположена в `admin/`, на том же GitHub Pages, что и сайт. Отдельный сервер авторизации не нужен: используется токен GitHub. Скрипты CMS, зависимости и переводы собраны локально; CDN для редактора не требуется. Для чтения и записи необходим доступ к GitHub API.

После публикации администратору нужно открыть `https://landat.github.io/step-static-website/admin/`. Первый вход и выбор типа токена описаны в `ADMIN_GUIDE.md` и `admin/help.html`. Токен не хранится в репозитории.

### Настройка и обновление CMS

Исходная схема `.pages.yml` сохранена как источник полей и возможность возврата к Pages CMS. `scripts/build-cms.mjs` переносит её поля в `admin/config.yml` и собирает закреплённую в `package-lock.json` версию Sveltia CMS. Все разделы редактируются одной формой, чтобы запись общего JSON не затёрла соседние разделы. Сборка не меняет контент и существующие медиафайлы.

```powershell
npm ci
npm run build:cms
npm test
```

Публикуйте `admin/config.yml` и весь каталог `admin/vendor` вместе с исходниками: текущий GitHub Pages публикует файлы из `main` без этапа npm-сборки. Не подключайте CDN вместо локальной сборки: это вернёт зависимость от доступности сторонних доменов. Сгенерированные файлы вручную не редактировать.

Загрузка медиа ограничена 50 МиБ на файл. Оптимизация новых фото по push сохранена. Ручной запуск доступен по ссылке из панели на существующий workflow `optimize-images.yml`; там нажать Run workflow для main. Вход по email Pages CMS не переносится: каждому редактору нужна своя учётная запись GitHub с записью в репозиторий.

### Приёмка после публикации

1. На устройстве тренера без VPN открыть `/admin/` и выполнить вход своим токеном.
2. Сохранить согласованное изменение, дождаться GitHub Pages и проверить результат на сайте.
3. Проверить фото, MP4/WebM, PDF и ссылку Rutube, а также автоматическое и ручное сжатие фото.
4. После проверки убрать старую ссылку `app.pagescms.org` из закладок. `.pages.yml` оставить: она используется сборкой новой CMS.

Выбор: [Sveltia CMS и вход токеном](https://sveltiacms.app/en/docs/backends/github). Альтернативы Decap CMS с обычным GitHub OAuth и собственная установка Pages CMS требуют дополнительного компонента авторизации или сервера; выбранный вариант обходится существующим бесплатным GitHub Pages.

## Деплой

Сайт опубликован через GitHub Pages из ветки `main`, путь `/`.

После любого изменения в GitHub и нажатия `Commit changes` GitHub Pages автоматически передеплоит сайт.

Публичный адрес:

```text
https://landat.github.io/step-static-website/
```

Меню панели и подписи разделов задаются в `admin/src/sections.js`, оформление — в `admin/panel.css`. Сборка также копирует `@sveltia/cms/npm/assets` (шрифты, иконки, кодеки); проверка `npm test` защищает от повторной потери этих файлов.

Плиточная композиция главной страницы оформлена в `assets/home.css`. `assets/home-motion.js` запускает однократное появление блоков при прокрутке; направление задаётся атрибутом `data-reveal`. На телефонах движение короче, при `prefers-reduced-motion` отключено. Без JavaScript все блоки видны. Эти файлы подключаются только на главной и не меняют схему CMS или формат `content/site.json`.

Облегчённые изображения главной лежат в `assets/optimized/` и пересоздаются командой `npm run build:home-images`. Скрипт сохраняет оригиналы; при замене декоративного снимка обновите источник в `scripts/build-home-images.mjs` и пересоберите версии. Для фотографии тренировки браузер выбирает размер через `srcset`. Видео школы загружается по нажатию Play, а данные CMS перепроверяются при каждом посещении с поддержкой HTTP-кеша.
