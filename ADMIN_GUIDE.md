# Инструкция администратора сайта

Все регулярно меняющиеся данные сайта редактируются через Sveltia CMS на самом сайте. Открывать HTML, JSON или JavaScript не нужно. CMS и её размещение на GitHub Pages бесплатны.

## Первый вход

1. После публикации новой панели откройте [управление сайтом](https://landat.github.io/step-static-website/admin/).
2. Для первой настройки используйте ссылку «Инструкция и первый вход» вверху панели. Разработчик должен проверить право записи вашей учётной записи GitHub и помочь создать ваш собственный токен доступа.
3. Нажмите «Войти с помощью токена доступа» и вставьте токен. Он сохраняется в браузере на этом устройстве.
4. Откройте «Содержимое сайта» → «Объявление, расписание и другие разделы».
5. Разверните нужный раздел. Репозиторий и ветка `main` уже выбраны в настройках панели.

Повторная настройка нужна при истечении срока токена, очистке браузера или смене устройства. Не сообщайте токен, пароль и коды входа другим людям. Токен нельзя добавлять в файлы сайта или присылать в чат.

### Токен для разработчика и для тренера

- Владелец `landat`: fine-grained token только для `step-static-website`, разрешение **Contents: Read and write**, Metadata: Read автоматически. Pull requests и Workflows не требуются. Выберите ограниченный срок, например 90 дней.
- Тренер с отдельным аккаунтом, приглашённый в этот публичный личный репозиторий: classic token с областью **public_repo**, например на 90 дней. GitHub пока не поддерживает fine-grained токены для записи в репозиторий другого пользователя в роли repository collaborator. Область public_repo действует на все доступные аккаунту публичные репозитории. Полные области repo и workflow здесь не нужны.
- Токен создаёт и использует сам владелец соответствующего аккаунта. Токен разработчика тренеру не передают. Создание токена не предоставляет доступ к репозиторию: сначала нужно принять приглашение.

[Настройка и ограничения токенов GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens).

## Главное правило

После изменения нажмите **Сохранить** (Save) один раз. Обычно сайт обновляется за 2–5 минут. Затем откройте изменённую страницу и обновите её сочетанием `Ctrl+F5`.

Все восемь разделов находятся в одной форме и сохраняются вместе. Не редактируйте сайт одновременно в нескольких вкладках или в старой Pages CMS. При сообщении о конфликте обновите данные и повторите изменения.

## Срочное объявление

В блоке «Срочное объявление» можно:

- показать или скрыть всю плашку;
- изменить заголовок и текст;
- изменить подпись перед расписанием;
- изменить название ссылки на схему проезда.

Группы и время в объявлении берутся из блока «Расписание и группы». Вводить расписание повторно не нужно.

## Расписание и группы

1. Откройте «Расписание и группы».
2. Для каждой группы заполните название, описание и время по дням.
3. Если в определённый день занятия нет, напишите `нет`.
4. Группы можно добавлять, удалять и менять местами.
5. Нажмите **Save**.

Одно изменение автоматически обновляет главную страницу, страницу «Расписание» и список групп на странице «Тренировки».

## Контакты

В блоке «Контакты» редактируются адрес, телефон, email, маршрут и карта. Телефон автоматически обновляется в шапке всех страниц.

Абзацы в поле «Как добраться» разделяйте пустой строкой. Для карты используйте ссылку виджета Яндекс.Карт, начинающуюся с `https://yandex.ru/map-widget/`.

## Цены

В блоке «Цены» можно изменить вводный текст, добавить варианты занятий, указать стоимость или описание, а также изменить пояснение и надпись на кнопке.

## Новости

1. Откройте «Новости» и добавьте элемент.
2. Укажите дату, заголовок и текст.
3. Оставьте «Показывать на сайте» включённым.
4. При необходимости включите «Закрепить первой».
5. Нажмите **Save**.

Новости автоматически сортируются от новых к старым. Закреплённые показываются выше остальных. Старую новость можно скрыть, не удаляя её.

## Фотографии

1. Откройте «Фотографии» и добавьте элемент.
2. Загрузите JPG, PNG или WebP.
3. В «Кратком описании» напишите, что изображено на снимке.
4. Нажмите **Save**.

Фотографию можно временно скрыть переключателем «Показывать на сайте». Перед загрузкой желательно уменьшить изображение до 2000 пикселей по длинной стороне.

После загрузки фотографии автоматически обрабатываются существующей задачей GitHub Actions. Для ручного сжатия нажмите «Уменьшить большие фотографии» вверху панели. На открывшейся странице GitHub выберите **Run workflow → main → Run workflow** и дождитесь зелёной отметки. Сжатие сохраняет адреса файлов.

## Видео для новичков

### Загрузить MP4 или WebM

1. Добавьте элемент в «Видео для новичков».
2. Укажите название урока.
3. В поле «Где находится видео» выберите «Загруженный MP4/WebM».
4. Загрузите файл в поле «Файл MP4/WebM».
5. Нажмите **Save**.

### Добавить видео Rutube

1. Добавьте элемент и укажите название.
2. Выберите «Rutube».
3. Вставьте обычную ссылку на ролик в поле «Ссылка на Rutube».
4. Поле файла оставьте пустым.
5. Нажмите **Save**.

Можно добавить несколько видео. Порядок роликов на сайте совпадает с порядком в CMS.

Лимит загрузки в панели — 50 МиБ на файл. Для больших видео используйте Rutube. В медиатеке есть отдельные разделы фотографий, видео и документов.

## Материалы для новичков

1. Добавьте элемент в «Материалы для новичков».
2. Заполните заголовок и текст. Абзацы разделяйте пустой строкой.
3. Если нужен файл, загрузите PDF, DOC или DOCX в поле «Файл для скачивания».
4. При необходимости измените текст кнопки.
5. Нажмите **Save**.

Материал без файла тоже допустим. Его можно скрыть переключателем, не удаляя.

## Если сайт не обновился

1. Подождите 5 минут и нажмите `Ctrl+F5`.
2. Убедитесь, что сохранение завершилось без ошибки, а публикация GitHub Pages прошла успешно.
3. Если на сайте появилась жёлтая полоса о недоступной информации, не вносите новые изменения до исправления ошибки и сообщите разработчику.

Если вход или загрузка данных не работают, проверьте срок токена и доступность `api.github.com` без VPN. Открывающаяся главная страница GitHub сама по себе не подтверждает доступность его API.
