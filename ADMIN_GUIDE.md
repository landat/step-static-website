# Инструкция администратора

Эта инструкция для человека, который не работает с кодом и хочет с другого компьютера заменить видео урока 1 или добавить новый материал для новичков.

## Как заменить видео урока 1

1. Войти в GitHub.
2. Открыть репозиторий `landat/step-static-website`.
3. Открыть файл `content/videos.js`.
4. Нажать кнопку редактирования с иконкой карандаша.
5. В первом блоке заменить ссылку в поле `src`:

```js
{
  title: "Урок 1. Как правильно бинтовать руки боксёру",
  src: "https://example.com/video.mp4"
},
```

6. Нажать `Commit changes`.
7. Подождать 2-5 минут.
8. Проверить страницу `https://landat.github.io/step-static-website/beginners.html`.

## Важно

- Кавычки вокруг текста удалять нельзя.
- Запятая после блока нужна, потому что ниже в файле есть служебный комментарий.
- Для MP4-видео используйте поле `src`.
- Для Rutube-видео замените `src` на `rutube` и вставьте обычную ссылку Rutube из адресной строки браузера.
- Простое добавление второго блока в файл сейчас не выведет второй ролик на странице: `beginners.html` показывает только первый ролик.
- Если сайт не обновился сразу, нажмите `Ctrl+F5`.

## Как добавить новый материал для новичков

Новый материал добавляется на страницу `beginners.html` через файл `content/beginners.js`.

1. Войти в GitHub.
2. Открыть репозиторий `landat/step-static-website`.
3. Открыть файл `content/beginners.js`.
4. Нажать кнопку редактирования с иконкой карандаша.
5. Скопировать пример блока из комментария внизу файла.
6. Вставить блок перед строкой `];`.
7. Заменить `title`, тексты в `paragraphs`, а при необходимости `url` и `linkText`.

Пример материала без отдельного файла:

```js
{
  title: "Урок 3. Передвижения",
  paragraphs: [
    "Первый абзац материала.",
    "Второй абзац материала."
  ]
},
```

Пример материала со ссылкой на файл:

```js
{
  title: "Памятка новичка",
  paragraphs: [
    "Короткое описание памятки."
  ],
  url: "assets/materials/beginner-checklist.pdf",
  linkText: "Открыть памятку"
},
```

## Как загрузить файл для материала

1. В репозитории открыть папку `assets/materials`.
2. Нажать `Add file` -> `Upload files`.
3. Перетащить PDF, картинку или другой файл.
4. Нажать `Commit changes`.
5. В `content/beginners.js` указать путь к файлу в поле `url`, например `assets/materials/beginner-checklist.pdf`.

## Проверка

После изменений подождите 2-5 минут и откройте:

```text
https://landat.github.io/step-static-website/beginners.html
```
