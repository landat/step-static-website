# Инструкция администратора сайта

Все регулярно меняющиеся данные сайта редактируются через Pages CMS. Открывать HTML, JSON или JavaScript не нужно.

## Первый вход

1. Откройте [app.pagescms.org](https://app.pagescms.org).
2. Войдите через GitHub.
3. Разрешите Pages CMS доступ к репозиторию `landat/step-static-website`.
4. Выберите репозиторий и ветку `main`.
5. Откройте пункт «Содержимое сайта».

Этот вход настраивается один раз. Не сообщайте пароль и коды входа другим людям.

## Главное правило

После изменения нажмите **Save** один раз. Обычно сайт обновляется за 2–5 минут. Затем откройте изменённую страницу и обновите её сочетанием `Ctrl+F5`.

## Срочное объявление

В блоке «Срочное объявление» можно:

- показать или скрыть всю плашку;
- изменить заголовок и текст;
- изменить подпись перед расписанием;
- изменить название ссылки на схему проезда.

Группы и время в объявлении берутся из блока «Расписание и группы». Вводить расписание повторно не нужно.

## Расписание и группы

1. Откройте «Расписание и группы».
2. Для каждой группы заполните название, описание и время по дням.
3. Если в определённый день занятия нет, напишите `нет`.
4. Группы можно добавлять, удалять и менять местами.
5. Нажмите **Save**.

Одно изменение автоматически обновляет главную страницу, страницу «Расписание» и список групп на странице «Тренировки».

## Контакты

В блоке «Контакты» редактируются адрес, телефон, email, маршрут и карта. Телефон автоматически обновляется в шапке всех страниц.

Абзацы в поле «Как добраться» разделяйте пустой строкой. Для карты используйте ссылку виджета Яндекс.Карт, начинающуюся с `https://yandex.ru/map-widget/`.

## Цены

В блоке «Цены» можно изменить вводный текст, добавить варианты занятий, указать стоимость или описание, а также изменить пояснение и надпись на кнопке.

## Новости

1. Откройте «Новости» и добавьте элемент.
2. Укажите дату, заголовок и текст.
3. Оставьте «Показывать на сайте» включённым.
4. При необходимости включите «Закрепить первой».
5. Нажмите **Save**.

Новости автоматически сортируются от новых к старым. Закреплённые показываются выше остальных. Старую новость можно скрыть, не удаляя её.

## Фотографии

1. Откройте «Фотографии» и добавьте элемент.
2. Загрузите JPG, PNG или WebP.
3. В «Кратком описании» напишите, что изображено на снимке.
4. Нажмите **Save**.

Фотографию можно временно скрыть переключателем «Показывать на сайте». Перед загрузкой желательно уменьшить изображение до 2000 пикселей по длинной стороне.

## Видео для новичков

### Загрузить MP4 или WebM

1. Добавьте элемент в «Видео для новичков».
2. Укажите название урока.
3. В поле «Где находится видео» выберите «Загруженный MP4/WebM».
4. Загрузите файл в поле «Файл MP4/WebM».
5. Нажмите **Save**.

### Добавить видео Rutube

1. Добавьте элемент и укажите название.
2. Выберите «Rutube».
3. Вставьте обычную ссылку на ролик в поле «Ссылка на Rutube».
4. Поле файла оставьте пустым.
5. Нажмите **Save**.

Можно добавить несколько видео. Порядок роликов на сайте совпадает с порядком в CMS.

## Материалы для новичков

1. Добавьте элемент в «Материалы для новичков».
2. Заполните заголовок и текст. Абзацы разделяйте пустой строкой.
3. Если нужен файл, загрузите PDF, DOC или DOCX в поле «Файл для скачивания».
4. При необходимости измените текст кнопки.
5. Нажмите **Save**.

Материал без файла тоже допустим. Его можно скрыть переключателем, не удаляя.

## Если сайт не обновился

1. Подождите 5 минут и нажмите `Ctrl+F5`.
2. Убедитесь, что редактировали ветку `main`.
3. Если на сайте появилась жёлтая полоса о недоступной информации, не вносите новые изменения до исправления ошибки и сообщите разработчику.
